Project Title:
First Naukri – From Campus to Corporate

Project Description:
First Naukri is a web-based job portal developed to connect freshers with recruiters. The system provides a centralized platform where students can search and apply for jobs, and recruiters can post vacancies and manage applications efficiently.

Key Features:
Student Module:
User Registration and Login
Profile Creation and Management
Job Search with Filters
Apply for Jobs
Application Tracking

Recruiter Module:
Recruiter Registration and Login
Post Job Vacancies
View and Manage Applicants
Manage Job Listings

Technologies Used:
Frontend: HTML, CSS, JavaScript, React
Backend: Node.js 
Database: MongoDB
Tools: VS Code

Project Structure:
frontend/ → User interface files
backend/ → Server-side logic
database/ → Database files / backup
